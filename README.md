# PureISP

PureISP 是住宅出口与中继分流项目，包含 Node.js 服务、Windows 便携客户端及 Clash Verge 集成组件。仓库目前包含原型逻辑：部分状态、测速和 IP 检测返回演示数据，不能作为实际网络质量或账号安全的证明。

## Windows 登录与浏览器修复：1.0.4

旧版覆盖用户环境变量，IDE 可能继承旧的 7897，退出时也没有恢复原配置。1.0.4 保留项目要求的系统代理自动接管：内核就绪后先备份原设置，通过 WinINet 接入 7890；退出恢复原设置。IDE 从面板启动时显式传入 7890 子进程环境，不修改或删除用户级代理变量。

使用 [修复版目录](dist/PureISP-BS-v1.0.4-Win64/PureISP-BS-Portable/) 或 [修复版 ZIP](dist/PureISP-BS-v1.0.4-Win64.zip)。先退出旧 PureISP，再打开修复版，普通浏览器自动通过系统代理使用双轨分流。IDE 请保存工作并完整退出后，从面板点击“启动 Antigravity IDE（独立代理）”。使用期间保持 PureISP 运行。

IDE 安装路径不固定盘符：自动读取安装信息和开始菜单/桌面快捷方式，找不到时手动选择一次并记住；可通过“选择 / 更换 IDE 路径”更改。

右上角 ✕ 和最小化收进托盘，代理继续工作；双击托盘图标或右键打开面板。只有“停止并退出”、托盘退出或正常关机确认才恢复原系统代理并停止内核。新增双轨分流图标，窗口、托盘和 exe 共用。

常用入口 `dist/PureISP-BS-Portable/PureISP.exe` 和中文“极简免安装版”ZIP 已同步为 1.0.4；历史包保留。

2026-10-10 本机验证：以修复后的子进程设置启动 IDE，新会话账号日志显示 `success` / `signedIn`。

## 运行 Node 服务

已在本机 Node.js `v24.14.0` 下验证。服务只使用 Node 内置模块，无需安装依赖。

```powershell
cd server
npm start
```

- 官网：`http://127.0.0.1:3600/`
- 控制台：`http://127.0.0.1:3600/console`
- 健康检查：`http://127.0.0.1:3600/health`
- 订阅：`/api/v1/subscription/<license>.yaml`

也可双击根目录 `start-server.bat`。`start-web-console.bat` 会另外启动 Node；已运行服务时直接打开控制台 URL，避免端口冲突。

Node 服务和 Windows 便携内核是两个独立入口。启动 Node 不会自动启动 Mihomo，也不会配置操作系统代理。
